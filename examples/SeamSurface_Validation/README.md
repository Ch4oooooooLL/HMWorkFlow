# Geometry Seam（几何焊缝）验证模型

本目录为几何焊缝模块（`modules/seam_surface`）的验证几何模型：一个 STEP 文件内含
16 个沿 X 轴隔离的场景（间距 400 mm），覆盖全部 12 类操作（正常 + 失败 + 边界），
几何输入全部为**开放壳体曲面**（顶面 + 侧边带，去掉底面），符合几何焊缝对边/面/点
的输入要求，且各场景之间、同一场景内两块板之间**不共享拓扑**。

## 1. 生成命令与依赖

几何生成需要系统 Python（本项目基线为 3.14）+ cadquery 2.8.0。在仓库根目录执行：

```powershell
python -c "import cadquery"   # 先验证 cadquery 可用（user site）
python .\examples\SeamSurface_Validation\generate_geometry.py
```

生成产物（均为 gitignore，不入库）：

- `SeamSurface_Validation.step` —— 交付用几何模型。
- `SeamSurface_Validation_manifest.json` —— 逐场景的选择实体、端点坐标、
  预期行为与参数（schema_version 1.0）。

生成器确定性：除 STEP 头部 `FILE_NAME` 的 ISO 时间戳由 OCCT 写入器自动生成外，
STEP 实体内容与 manifest 逐字节确定（manifest 完全确定）。生成器内置自检，任何
数值/拓扑与设计不符会 `raise`，不会写出错误产物。

## 2. 模型结构

坐标单位 mm。所有壳体 z=0 起厚 2.0 mm（C03/C04/C06/C14 上板抬高到 z=3~5 形成
1 mm 间隙）。每个场景是一个"真实钣金总成局部"：板带翻边/缺口/孔，焊缝路径为
折线/狗腿形（而非单一直线），T 型筋板高 20~60 mm。

| 场景 | 操作 | 位置 (x) | 要点 |
| --- | --- | --- | --- |
| C01 | T 路径 | 0–260 | 底板带 8 mm 下翻边 + 2 孔；L 形筋板（高 50） |
| C02 | T 列表 | 400–660 | 同一底板 1 直筋 + 1 折弯筋，底板含孔 |
| C03 | 搭接面 | 800–1080 | 两平行板重叠区 70 mm，间隙 1.0 |
| C04 | 搭接边 | 1200–1490 | 上板台阶形（缺口）搭接边 → 下板顶面 |
| C05 | 连接 | 1600–1920 | 两共面板狗腿形对边，法向间隙 0.76–0.8 |
| C06 | 投影/分割 | 2000–2180 | 楼梯形源板底边投影切分目标板 |
| C07 | 延伸 | 2400–2720 | 筋板底边距底板 4 mm，短边延伸 |
| C08A | 合并 | 2800–2930 | 两块共面相邻顶面（共享边） |
| C08B | 拆分 | 2960–3100 | 独立折线投影切分目标板 |
| C08C | 替换点 | 3120–3180 | 自由点投影到边线 |
| C09 | 失败：大角度斜交 | 3200–3460 | 45°（非平行非垂直） |
| C10 | 失败：超距 | 3600–3860 | 间隙 8 mm（> distance_tolerance 1.0） |
| C11 | 失败：短焊缝 | 4000–4260 | 边 4 mm（< min_seam_length 5.0，边界） |
| C12 | 边界：斜 T 型 | 4400–4660 | 法向夹角 70°（< 垂直下限 75°） |
| C13 | 分布点 | 4800–5060 | 260 mm 边按 7 mm 分布点 |
| C14 | 删除 | 5200–5400 | 先创建搭接焊缝再删除 |

## 3. 导入与操作步骤（HyperMesh 2019）

1. 启动 HyperMesh 2019（经典界面），新建模型。
2. File → Import → Geometry，选择 `SeamSurface_Validation.step`，单位 mm。
3. 打开"几何焊缝"面板（工具箱 → Geometry Seam，或快捷键）。
4. 按 manifest 各 case 的 `selection` 逐项选择：
   - **边**：使用 `identify`（边中点坐标）确认，端点见 `endpoints`，可按
     "by id" 或坐标定位；选择"边线路径"（Create List / By Path）时沿路径点选。
   - **面**：用 `identify`（面内一点坐标）确认。
   - **点**：用 `coordinate` 坐标确认。
5. 执行对应操作按钮（T路径/T列表/搭接曲面/搭接边线/连接边线/投影切分/延伸/
   合并/拆分/替换点/分布点/删除）。
6. 创建类操作（T路径/T列表/搭接曲面/搭接边线/连接边线/投影切分）为连续模式，
   完成后按 Esc 退出；其余为单次模式。
7. 对照 manifest 的 `expected` 与模块面板状态/运行目录日志
   （`runtime/tasks/seam_surface/<run_id>/`）。

## 4. 预期结果（对照 manifest）

- **C01 T路径**：L 形路径（60,30,3）→(60,90,3)→(100,90,3) 创建 T 焊缝条带，条带
  归入 `SEAM_Txx_Surf` 组件并与底板顶面共享边线。底板为翻边板（z −8..2，含 2 孔）。
- **C02 T列表**：3 条筋底边（筋1 单条 + 筋2 折弯两条）一次选择，拓扑归类 LIST，
  对同一目标面创建多条焊缝。
- **C03 搭接面**：平行板重叠区（x≈880–950）创建搭接焊缝面。
- **C04 搭接边**：上板两条台阶形自由边（x=1310 与 x=1370，z=3）向下创建焊缝到下板顶面。
- **C05 连接**：两共面板狗腿形对边之间创建直纹面并缝合（竖段间隙 0.8、斜段法向 0.76）。
- **C06 投影/分割**：L 形投影线切分目标板顶面。
- **C07 延伸**：沿筋板底边（z=6）创建延伸面，桥接 4 mm 间隙；可能伴随源面重编号警告。
- **C08A 合并**：两共面顶面合并为一张面（若导入时已缝合则报 already equivalent 警告）。
- **C08B 拆分**：独立折线投影切分目标板。
- **C08C 替换点**：自由点 (3150,120,5) 投影到边线，落到 (3150,130,2)。
- **C13 分布点**：260 mm 边按 7 mm 间距生成 36 个分布点。
- **C14 删除**：先对 (5280,0,3)–(5280,120,3) 创建搭接焊缝，再选择该焊缝删除。

## 5. 失败形态的验证方式

> 重要前提（在 `modules/seam_surface/executor.tcl`、`selector.tcl` 源码中确认）：
> v2 手动执行流**不**在 Tcl 侧对"平行/垂直分类、边到面距离、最短焊缝长度"做显式
> 校验。分类（15°/75°）、距离与引导角度全部交由原生 `*connect_surfaces_11` 决定
> （`connect_min_angle_to_target=15`、`connect_max_angle_edge_to_surf=30`、
> `connect_guide_angle=30`；`distance_tolerance`、`min_seam_length`、
> `angle_parallel_max`、`angle_perpendicular_min` 目前仅为文档化配置项）。
> 因此失败场景的"预期"是：原生命令不创建焊缝并抛错（如
> "The native extension created no seam surface"），或需要人工确认，模块不崩溃。

- **C09 大角度斜交（45°）**：筋面法向与底板法向夹角 45°，在平行（≤15°）与垂直
  （≥75°）分类之间。预期拒绝/无焊缝。请记录实际观测（可能因原生角度阈值而拒绝）。
- **C10 超距**：筋板底边距目标面 8 mm（> distance_tolerance 1.0）。预期报错
  "The native extension created no seam surface"。
- **C11 短焊缝（4 mm 边）**：边长 < min_seam_length 5.0。因 executor 未强制该参数，
  操作会照常执行（可能创建微小焊缝或原生失败）——请记录实际行为，用于评估是否需要
  在模块中补充显式长度校验。
- **C12 斜 T 型（70°）**：法向夹角 70°，在垂直下限 75° 之下但接近。边界探测场景，
  观察原生命令是否接受。

失败场景验证要点：模块**不崩溃**、明确拒绝或报错、日志/面板给出可核对的提示。

## 6. 边界与注意事项

- 模型仅用于识别与流程验证（模块操作、选择流程、输出组件、日志核对），
  **不是生产求解模型**。
- 两块板之间刻意保留 0.76–8.0 mm 间隙、不共享顶点：几何焊缝针对非共拓扑输入。
- 全闭合接头（两板间隙 0 且完全接触）是模块已知的失败输入（无间隙可桥接），
  本模型刻意保持 1–8 mm 间隙以便观察正/负两类行为。
- 分布点（C13）、替换点（C08C）、投影/拆分（C06/C08B）、删除（C14）不创建
  焊缝面，只有 C01/C02/C03/C04/C05/C07 创建 `SEAM_Txx_Surf` 面。
- C07 延伸依赖 `extend_offset_distance`（默认 12.0）；C03 搭接面依赖
  `geometry_offset_distance`（默认 50.0）与 `lap_boolean_opcode`（默认 8=并集）。
