HyperMesh Toolkit 快速启动

面向 HyperMesh 2019 的 Tcl/Tk 结构化前处理工具集。项目将常用的车身和结构件前处理动作组织成一个一体化主入口，规范化流程、提高网格与连接创建的效率。

提示：关于已隐藏的模块说明

本项目包含部分底层与准备工作流模块（例如 Component 分类、材料分配、中面提取、自动 Washer 划分、铸件网格等），这些模块由于仅在开发或快捷键中隐式调用，在主面板中已被设为隐藏，使用本指南时无需关注。您只需处理主面板上可见的 9 大核心模块。

安装与更新指南

本工具箱支持在 HyperMesh 中通过简单的 TCL 运行来完成首次注册或路径自动更新，并将快捷键直接持久化在系统原生配置文件中。

快捷键绑定与自动加载配置
install_update.tcl

推荐的首次安装与更新工作流

在 HyperMesh 中，点击顶部菜单 File > Run > Tcl/Tk Script，选择运行项目根目录下的 install_update.tcl。它会自动引导配置并修复快捷键机制。

工作原理与步骤说明

  1. 注册主面板快捷键：首次运行会提示用户输入快捷键（默认建议 Ctrl+Shift+W），写入原生 Key Commands 库。
  2. 修改 hmcustom.tcl：脚本会在用户主目录下的 hmcustom.tcl 尾部写入加载块标记： 
    # >>> HMWorkFlow shortcut loader >>>
set ::HMWorkFlow_Dir "C:/path/to/project"
source [file join $::HMWorkFlow_Dir "shortcut_bootstrap.tcl"]
# <<< HMWorkFlow shortcut loader <<<
    该区块确保 HyperMesh 启动时静默注册快捷键，不会覆盖您原有的其他自定义 TCL 代码。
  3. 配置备份路径：快捷键配置文件保存在本地用户目录 %APPDATA%\HMWorkFlow\shortcuts.cfg。当项目移动或拷贝到其他路径后，再次运行 install_update.tcl，点击 “修复自动加载 / Repair Loader” 即可一键更新为当前项目路径。

使用约束与防冲突提示

1. 避免高危键位：请不要绑定 Ctrl+S, Ctrl+O, Ctrl+Z, Ctrl+Y 以及 F1~F10，因为它们是 HyperMesh 原生的撤销/保存/视图核心按键，强行覆盖会导致建模异常。
2. 快捷键独立运行：通过快捷键直接调用的模块会直接以默认状态运行，不打开主窗口界面，保证了连续建模时的工作流速度。

1. 几何清理 (Geometry Cleanup)

几何 几何清理: 倒角与沉台
modules/geometry_cleanup.tcl

该模块是一个一键式局部几何清理入口。用于修补三维实体模型中冗余或影响网格画分的局部特征，主要解决两大类问题：

  • 倒角 / 圆角特征消除 (CHAMFER/FILLET)：通过智能扩展特征相邻的面，重建倒角面使其恢复直角拓扑，并支持自动缝合与 Solid 重新生成。
  • 沉台 / 凹槽消除 (POCKET/RECESS)：自动识别沉台特征的内部侧面和基准平面边，通过把特征侧面封闭并与基准面的特征点、基准边直接对齐并补面，来快速消除沉台凹槽。

智能回滚安全机制

如果在几何清理（如面扩展缝合）过程中发生几何断裂或失效，模块会自动撤销（Undo）本次修改，并确保不会对已有的正常几何体造成破坏，提示您调整参数或手动处理。

1
启动工具
在主面板运行 Geometry Cleanup: Chamfer/Recess 或触发相应快捷键。
2
设置工作模式与容差
在界面上选择 AUTO（自动模式）、CHAMFER（倒角清理模式）或 POCKET（沉台清理模式），并填入圆角过滤半径与缝合容差（一般为 0.2）。
3
进入连续清理模式
点击 “进入连续清洗” 按钮，软件会将控制权移交给 HyperMesh 的面选取面板。
4
选择表面并执行
在图形窗口中选择需要清理的倒角斜面、圆角面或沉台底面，按 鼠标中键 执行。程序会自动识别链式面并缝合。完成后可直接点击下一个面，按 ESC 可随时退出连续清理。
参数 Key 默认值 说明与作用
mode AUTO 清理模式。可选值：AUTO（智能识别）、CHAMFER（仅清理倒/圆角）、POCKET（仅清理沉台）。
fillet_min_r 0.0 面过滤最小半径。过滤极小碎面。
fillet_max_r 5.0 面过滤最大半径。圆角过滤的上界半径。超过此半径的特征面不处理。
chain_by_fillet 1 (开启) 当开启时，程序会使用 HM 内部算法自动基于所选面进行圆角面链（Fillet Chain）扩展，实现批量清理。
chain_by_small_area 1 (开启) 如果无法识别标准圆角，则开启小面积相邻面作为回退链式搜索（Fallback Chain）。
max_chain_depth 6 链式相邻面搜索的最大深度层数，防止过度选择。
area_growth_ratio 2.5 允许扩展相邻面的最大面积比。相邻面面积 ≤ 当前所选面面积 × 此比例时，才会被一并选中清理。
stitch_tolerance 0.2 几何重构后的面缝合（Stitch）容差，单位为模型单位。
create_solid_from_chamfer_bounds 1 (开启) 当曲面面扩展清理完倒角后，自动尝试通过缝合边界重新在零件上创建闭合实体（Solid）。

局部几何修改；请逐面确认

模块以单个种子面为入口。AUTO 会先尝试倒/圆角清理，失败后才尝试沉台补平；链式扩展受 MAX_CHAIN_DEPTH 与面积比例限制。每次处理均建立 HyperMesh 历史状态，失败会撤销本次处理，但成功结果仍应检查缝合、边界与实体闭合情况后再继续。

  • 仅适用于局部倒角、圆角和规则沉台；多分支、破损拓扑或复杂过渡面应改为手工处理。
  • STITCH_TOLERANCE 是模型单位下的拓扑容差；过大可能误缝合相邻特征，过小可能无法闭合。
  • 开启实体重建只在倒角清理后尝试；生成前请保存模型或建立检查点。

2. 网格焊缝 (Mesh Seam Weld)

网格 网格焊缝连接带创建
modules/mesh_seam_weld.tcl

该模块主要用于处理车身结构件之间的焊缝面（Seam Surface）网格创建。它打破了传统几何 Ruled 面划分网格的低效率，采用了在已有网格上直接投影的流程：

  • 节点选择：连续的一串节点按开放 node path 处理。单点及不连续边界种子通过 HyperMesh 2019 原生 *findedges 为每个源 component 创建临时隐藏 PLOTEL 自由边组件；自由边点只提取包含该节点的闭环，内部点提取其所属整个 component 的全部闭合自由边。路径提取完成后临时组件立即清理，原有 ^edges 会被保留和恢复。运行流程不导出 FEM，也不调用 Python。
  • 印记区网格重构 (Remeshing)：在印记边界内，自动计算重构范围，并将投影线与目标网格强行对齐重划分。
  • 自动生成 Ruled 连接带：自动利用两组特征点对齐，生成两个零件之间均匀的 shell 网格连接带，并将新生成的焊缝网格归类至指定组件。
  • 局部失败隔离：每个闭环都在独立撤销事务中完成即时目标 patch、imprint、后置节点验证和连接带创建。任一阶段失败会回滚并跳过当前闭环，不会退化为整个目标 component 的 imprint，也不会保留部分焊缝。
  • 批量性能与可靠性：原生自由边 PLOTEL 连接关系通过一次 mark 批量读取；每条路径执行前才统一投影全部源节点、一次反查所附着的目标壳单元并扩展两到三层 Elements，避免前一条路径重网格后留下过期目标单元 ID。imprint 后优先采用 HyperMesh 提供的结果节点列表；程序按几何方向建立单调节点对应，并将对应关系切分为连续有效区段。找不到对应节点或目标网格边不连续的局部区段会被跳过，其余区段仍正常创建。列表不可用时，仍通过当前局部 patch 的有界拓扑追踪恢复目标路径。边界遍历、投影、验证和连接带创建等长循环会按固定批次处理界面事件。
  • 可反馈诊断：失败会按目标准备、imprint、目标匹配、目标连续性、automesh 或撤销事务分类，显示原因和检查建议，并在任务目录写出 UTF-8 纯文本 mesh_seam_weld_failure_report.txt。反馈问题时同时提供该文件和 operation.log 即可。
  • 裁剪与回滚兼容：目标节点通过目标 component 的 element mark 和局部最近节点查询获得，新焊缝单元通过输出 component 操作前后的集合差异识别，不依赖实体 ID 单调增加；模型经过裁剪、删除、导入或撤销后仍可继续执行。
1
运行网格焊缝工具
在面板运行 Mesh Seam Weld 模块。
2
选择源 node path
多选连续节点时使用所选开放路径。单点及不连续种子由原生 *findedges 创建一一对应的临时自由边组件：自由边点只选择所在闭环；内部点选择该源 component 的全部闭合自由边。开放、分叉或非流形边界会直接拒绝。
3
选择目标组件
选择需要焊缝投影的一个或多个目标面组件（Components）。每个闭环独立尝试向所选目标组件投影。
4
配置生成参数
填写焊缝尺寸、网格面形与平滑参数，点击 “生成”。程序逐闭环即时准备当前目标网格的两到三层局部 patch，执行 imprint_nodelist，再按几何方向和闭环起点进行防扭曲对齐。随后逐节点建立对应关系，只对源、目标索引连续且目标网格边相邻的区段创建结构化连接带；找不到对应关系的局部区段会直接跳过。只有整条路径都不足以形成一个有效区段，或实际建带失败时，才回滚当前闭环并生成失败标记与报告。
参数 Key 默认值 说明与作用
output_component MESH_SEAM_WELD 输出网格焊缝单元存放的组件名称。
weld_mesh_size 8 生成焊缝的默认网格尺寸；路径方向和横向分层均使用该尺寸。
patch_expand_layers 2 印记影响区外扩的单元层数，控制局部重划分网格的平滑过渡范围。
imprint_remain 3 印记位置投影时的控制精度级别，参数越大投影位置越保真。
imprint_remesh_mode 2 印记对齐重划分网格的方法。2 表示优先保留周边质量的混合重新网格化。
imprint_angle 30.0 投影时的面法线夹角阈值。超出此夹角的平面印记将不予投影，防止投影穿透。
mesh_elem_type 2 焊缝单元的形状类型。常用：1 (三角形单元) / 2 (四边形为主单元)。
mesh_face_shape / mesh_smooth_method / mesh_smooth_tol1 / 1 / 0.5自动网格面形、平滑方法与平滑容差；mesh_smooth_tol 必须为正数。
mesh_size_control / mesh_skew_control1 / 1传给自动网格的尺寸与 skew 控制开关。
mesh_path_param / mesh_cross_param1 / 1连接带沿路径与横向边的最小单元密度；实际密度按 ceil(边长 / weld_mesh_size) 计算，焊缝宽度超过网格尺寸时自动生成多层。
create_geometry_surf0是否保留临时焊缝几何 surface；默认关闭，仅保留生成的焊缝单元。

会重构目标组件的局部网格

此模块并非只创建新单元：imprint_nodelist 会在目标组件写入节点路径并进行局部重划分。请先保存模型，并在生成后检查印记区域的单元质量、法向和连接关系。

  • 闭环种子仅接受唯一、无自交、每个节点恰有两条自由边的闭合流形；多个种子必须对应可识别的闭环。
  • 连续多节点严格按开放路径处理；imprint 后会比较正反方向，闭环还会校正起点，避免首尾交叉连接。
  • 批量闭环任务只允许一个目标组件，并通过命令流进度窗口逐环提示。
  • 输出组件为空、焊缝尺寸非正、扩展层数或网格枚举参数为负时会被拒绝。

网格焊缝完整性检查 (Mesh Weld Integrity Check)

网格网格后遗漏焊缝候选审查
modules/weld_integrity_check.tcl

模块在主要网格和连接完成后，自动缩小人工漏焊检查范围。首版只分析 Shell–Shell：Python 从壳拓扑推导自由边，经过 Component AABB 粗筛、空间哈希近邻搜索和连续边区域过滤，按 Component Pair 汇总候选。它不会判断某处必须焊接，也不会创建焊缝或修改模型。

1
定义检查范围
选择至少两个待检查 Component，或使用当前可见组件；可另选排除组件。
2
执行检测
设置距离、最短连续长度和连续节点数后开始。结果按候选总长度排序。
3
逐组审查
使用孤立、高亮区域、上/下区域定位候选；完成后自动进入下一条待检查 Pair。
4
恢复与继续
完成项可在状态筛选中重新打开。恢复按钮和关闭报告都会还原进入模块前的 Component 显示集合；再次进入可继续上次审查。
参数说明
最大搜索距离自由边节点与另一 Component 网格节点的最大允许距离，单位跟随模型。
最小有效接近长度连续候选自由边链累计长度低于该值时过滤。
最小连续节点数过滤单角点和少量零散近邻。
忽略共节点组件对共享节点达到连续节点阈值时，认为已经直接连接并跳过。

候选必须人工确认

首版使用自由边节点到目标网格节点的距离近似，不做 CAD 曲面投影。粗网格、错位网格或目标面内部节点稀疏时可能漏报；Shell–Solid、Solid–Solid 和自动建焊缝尚未实现。

3. 壳孔 RIGIDS (Shell Washer-Hole RIGIDS)

连接 壳网格 Washer 孔刚性连接
modules/shell_washer_hole_rbe2.tcl

该模块（内部命令为 ::RB2W::runAction）主要用于为已划分 Washer 网格的钣金壳（Shell）圆孔批量生成刚性连接单元。刚性类型可选 RBE2 或 RBE3，用于适配刚性传力或分布式耦合的建模需要：

  • 自动识别标准 Washer 孔环：将用户所选的全部 Components 一次性导出为合并 OptiStruct FEM，由 Python 批量扫描自由边（Free Edges）圆孔并生成增量 FEM，再导回当前 HyperMesh 会话；默认筛选孔径处于 6.0mm ~ 30.0mm 之间的孔。
  • 椭圆孔（Oval Holes）适应性：支持椭圆孔识别，并具有中心偏移容差与长短轴拟合校对功能。
  • 防重复建模机制：在执行前，工具会按孔边界节点集合检查已有 RIGIDS；还可检查源组件与已有输出组件（例如 AUTO_RBE2_<Source>）。发现重复候选会跳过并报告，防止重复建模。
  • 未使用 RBE2 清理：在 More / 设置子页点击按钮后直接导出全模型 FEM，并由 Python 批量检查所有 RBE2。只有中心节点除自身外未被任何其他单元引用的 RBE2 才会被预选；被 CBEAM、其他 RBE2、RBE3 或任意其他单元连接的候选均视为已使用。识别后自动进入 Delete 面板供人工复核。
1
运行壳孔 RIGIDS
在主面板运行 Shell Washer-Hole RIGIDS 模块。
2
选择组件
点击 “选择/重选组件”，在窗口中选择包含已划分 Washer 螺栓圆孔的壳网格组件。
3
参数定义
检查孔径范围、Washer 判定容差，并选择刚性类型：RBE2 以 RBE2_DOF 直接耦合；RBE3 使用相同 DOF 创建分布式耦合。
4
执行生成
点击 “开始创建 RBE2”。如需全覆盖重写，可以运行 “重建模式”。生成的 RBE2中心节点位于圆孔几何中心，依赖节点会自动连接到孔边缘。
5
检查未使用 RBE2
在 More / 设置子页点击 “检测未使用 RBE2” 后无需选择单元。工具自动导出全模型 FEM，由 Python 按中心节点的全部单元连接关系筛选，并将真正未连接的 RBE2 预选到 Delete 面板。
参数 Key 默认值 说明与作用
MIN_HOLE_DIAMETER 6.0 允许处理的螺栓孔径下限，小于此孔径的圆孔将被过滤。
MAX_HOLE_DIAMETER 30.0 允许处理的螺栓孔径上限，大于此孔径的圆孔将被过滤。
CIRCULARITY_TOL 0.08 标准圆形孔的最大椭圆度偏差，越小表示检测越严格。

仅处理具有有效 Washer 环的自由边孔

源码会跳过非闭合自由边、孔径/节点数超限、圆度或椭圆拟合不合格、Washer 宽度与内外环不匹配的候选。重建模式会删除相应输出组件后重建，请确认输出前缀与选择范围。

  • 默认只移动新建 RIGIDS 单元至输出组件，不移动原始节点或壳单元。
  • RBE2 会引入刚性约束，RBE3 的受力分配也依赖孔环质量；应由分析工程师确认与求解器建模规范一致。
  • 安全检查以已识别的 RIGIDS 为准，不能替代模型整体的重复约束、自由度和连接质量检查。

4. 实体孔 RIGIDS (Solid Through-Hole RIGIDS)

连接 实体孔 RBE2 自动创建
modules/auto_hole_rbe2.tcl

该模块（内部命令为 ::AutoHoleRBE2::runAction）是专门针对三维实体（Solid）六面体或四面体网格中贯通孔而设计的自动建模工具：

  • 自动识别圆柱形内表面：在实体网格上先提取自由面（Face Component），检测倾斜夹角与特征角，拟合圆柱面片。
  • 提取贯通孔端环：匹配圆柱体孔的两端端部节点，将其投影/合并到圆心线，定位三维圆柱轴线及中心点。
  • 生成实体 RIGIDS：将该孔圆柱内壁的所有受力节点（Wall Nodes）提取为依赖节点（Dependent Nodes），并在拟合出的贯通中心线上创建中心节点；刚性类型可选择 RBE2 或 RBE3。
1
运行实体孔 RIGIDS
在主面板运行 Solid Through-Hole RIGIDS 模块。
2
选择实体网格
点击 “选择/重选组件” 选择需要提取贯通孔的三维实体（Solid）组件。
3
设定拟合参数
填入法线角度差（通常在 35° 左右）和圆柱拟合容差（cylFitTol, 0.25）。若有特定孔径需求，可设定最小/最大半径过滤。
4
执行并清理临时面
点击确定开始拟合，工具会在内部自动创建 ^faces 临时面并提取孔壁，生成 RBE2 后自动删除临时面以保证模型整洁。
参数 Key 默认值 说明与作用
featureAngleDeg 78.0 提取自由面面片时的特征边界检测角度，用于隔离不同的体倒角。
loopNormalTolDeg 35.0 孔壁面片法线与拟合圆柱中心线法线的最大法夹角容差，超出的面片排除在孔壁外。
cylFitTol 0.25 圆柱拟合度（Cylinder Fitting Tolerance）偏差。越小说明孔的圆度需要越标准。
minRadius / maxRadius 0.0 / 0.0 孔的半径范围约束，设为 0 表示不做范围限制（无限制检测）。
rigidType / dofRBE2 / 123456刚性类型可选 RBE2 或 RBE3；dof 为耦合自由度集合。

resultCompName RBE2_HOLE_AUTO 生成的实体孔 RBE2 单元输出的目标 Component 名字。

只面向规则圆柱贯通孔

该模块针对正常的实体网格圆柱贯通孔。沉孔、倒角明显的孔、长圆孔、异形孔、多段孔道，以及表面拓扑破损或严重重复自由面的模型均不建议使用。

  • 运行中会创建 ^faces 临时自由面组件；preDeleteOldFaces 或 deleteTempFaces 开启时会删除同名临时组件，勿将业务实体放在该名称下。
  • 孔拟合失败或环线不足会跳过并写入日志；请根据日志和输出组件复核候选。
  • 生成 RIGIDS 前应确认实体孔的载荷传递假设，避免与其他 MPC/RBE 造成重复约束。

5. 螺栓连接 (RIGIDS Bolt Connector)

连接同轴 RIGIDS 中心线螺栓梁创建
modules/rbe2_bolt_connector.tcl

模块将用户选区导出为精简 OptiStruct FEM，由 Python 直接解析 RBE2 独立中心节点、完成共轴分组，并生成只包含新增 CBEAM/CBAR、属性和材料的增量 FEM。随后 Tcl 在当前 HyperMesh 会话中导入增量文件并核验每个梁的端点。梁单元按推算的偶数名义孔径归入 BOLT_Dxx_CBEAM（或 CBAR）组件。

  • 共轴分组：平面 RIGIDS 只沿其检测到的法线方向参加分组；空间型 RIGIDS 仅组成的组会预览并跳过，避免在不确定方向上错误连梁。
  • 直径与属性：按中心至依赖节点的有效最小半径推算直径并向下取偶数；未指定属性时会创建或复用对应 PBAR/PBEAM 与默认 MAT1。
1
配置输入范围
在 More / 执行面板选择 elements（直接选 RIGIDS）或 components（扫描所选组件内的 RIGIDS）。
2
设定分组规则
建议先用 axisMode=AUTO；按装配方向需要可指定 X/Y/Z，并确认 gapTol 与 offsetTol。
3
预览后创建
首次建议开启 dryRun，检查分组；确认后生成 CBEAM/CBAR。
参数 Key默认值说明与作用
selectModecomponents输入模式：默认从所选组件中筛取 RIGIDS；也可切换为 elements 直接选择 RIGIDS。
axisModeAUTO分组轴向：AUTO、X、Y 或 Z。
gapTol / offsetTol100.0 / 5.0相邻层沿轴向最大间距与横向偏心容差；超过任一条件不连梁。
minGroupSize / minBeamLength2 / 0.001最少分组记录数及允许创建的最短梁长。
planeAbsTol / planeFlatRatio0.5 / 0.12判定 RIGIDS 是否为平面型并限制其可用分组轴的容差。
radialAbsTol / radialRelTol0.5 / 0.08依赖节点半径一致性筛选的绝对/相对容差，用于可靠估算螺栓直径。
elemType / compPrefixCBEAM / BOLT输出梁类型及输出组件前缀。
propName空指定已有 1D 属性；留空时工具按直径创建或复用属性和默认材料。
dryRun0开启后仅预览分组、不创建或导入增量 FEM，建议首次运行使用。

分组结果必须复核

该工具仅连接满足几何容差的相邻中心节点，不会移动节点；仍应由用户确认每组代表同一物理螺栓。

  • 不足两个可用 RIGIDS、纯空间型分组、过短梁或不满足平面/共轴判定的候选会跳过。
  • gapTol、offsetTol 过大可能串接相邻螺栓，过小则可能漏连；应与模型单位和装配公差匹配。
  • 自动生成的 PBAR/PBEAM 与 MAT1 是可求解的默认兜底，不替代项目的材料、截面和预紧规范。

6. 创建 CBUSH (CBUSH Creator)

连接源节点 Z+5 CBUSH 快速创建
modules/cbush_creator.tcl

启动后直接打开 HyperMesh 原生节点选择器。选择一个或多个节点并中键确认后，工具逐个读取所属 component，在相同 X/Y、全局 Z+5 处创建临时节点，再创建 Spring config 21 / CBUSH type 6 单元。同一 source component 中的节点会复用同一个 CBUSH 输出 component。

1
选择源节点
可选择一个或多个节点；中键确认，Esc 取消。
2
批量创建
输出 component 名为 CBUSH_<源 component 名称>，每个临时节点的 Z 坐标增加 5；单点失败不影响其余节点。
3
检查求解属性
模块仅创建 CBUSH 拓扑；请按项目要求分配并检查 PBUSH 属性、方向和坐标系。

组件归属必须唯一

源节点无法识别所属 component，或同时关联多个 component 时，工具会停止。CBUSH 创建失败时，本次新建的临时节点会自动删除。

8. 模型打胶 (Adhesive Connector)

连接Area / adhesives 创建与越界清洗
modules/adhesive_connector.tcl

模块连续调用两次 HyperMesh 原生选择器：第一次选择 elems 作为 location，第二次选择至少两个 comps 作为 links。创建固定使用 Area / adhesives / no-skip post script。

1
选择 location 与 links
先选打胶区域壳单元并中键确认，再选择需要连接的组件。
2
设置参数
Tolerance=50、Coats=1；厚度固定为 const_thickness，默认值 1。
3
清洗并创建
HyperMesh 原生多线程投影会检查每个 location elem 的全部节点；任一节点未被任一非自身目标组件接受，即剔除整个单元。

投影范围是硬性条件

目标组件完整网格不再读入 Tcl；原生搜索直接支持 shell/solid faces，并与 connector 投影规则保持一致。创建后还会检查 connector 是否为 REALIZED。首次投产前请在目标 HM2019 / OptiStruct 环境做 smoke test。
